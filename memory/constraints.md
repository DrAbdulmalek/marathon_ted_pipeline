# Constraints — القيود الصارمة (لا تُخترق)

> خرق أي قيد هنا = فشل المهمة مهما بدا الإنجاز.

---

## C-006: لا تفترض APIs المكتبات

قبل استخدام أي مكتبة خارجية، افتح مصدرها المثبت أو شغّل سكربت تحقق.
**المرجع**: L-004، scripts/check_surya_api.py نموذجًا.

## C-005: فشل البوابة → STOP فوري

لا "أصلح بسرعة"، لا "أكمل لاحقًا"، لا تجاوز بوابة.
**المرجع**: AGENTS.md — القاعدة الصفرية #3.

## C-004: لا GPL/AGPL في نوى MIT

PyMuPDF، PyQt5، TriliumNext، Logseq، OpenProject، Taiga — لا تُدمج في النواة.
البدائل: pypdfium2، PySide6، خدمات خارجية، extras/subprocess معزول.
**المرجع**: D-001، جدول التراخيص في تحليل FineReader.

## C-003: لا أسرار في المستودع

`.env`، `.secrets/`، `*.session`، أي توكن — من البيئة حصرًا (GIT_ASKPASS/متغيرات).
لا يُطبع سر ولا يُكتب في ملف متعقب أو commit أو URL.

## C-002: لا force-push ولا amend لما دُفع سابقًا

حتى على الفروع الشخصية. التاريخ خطي وشفاف.

## C-001: main لا يُلمس على GitHub

- main على GitHub: ممنوع الدفع إليه مباشرة (فروع فقط + PR مسودة).
- main محلي في مساحة عمل بلا remote: لا يُدفع لاحقًا إلا عبر فرع.
- الملفات المشتركة تُثبت على main المحلي فقط عند غياب remote كليًا.
- **التوزيع المشترك يمر عبر sync-harness.sh — بلا force، بلا حذف.**
